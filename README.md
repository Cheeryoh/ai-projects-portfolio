# Justin Oh | Project Portfolio

Source for [cheeryoh.com](https://cheeryoh.com), my portfolio of applied AI, certification, assessment, and learning systems.

The site brings together project walkthroughs and supporting architecture and provenance notes. See my [GitHub profile](https://github.com/Cheeryoh) for selected public repositories.

## Structure

- `index.html`, `main.js`, and `style.css`: main portfolio site.
- `assets/`: site assets.
- `walkthrough*.html`: project walkthroughs for certification, assessment, and JTA systems.
- `consult.html`: consulting information.
- `docs/`: design and verification documentation.

Built with static HTML, CSS, and JavaScript.
